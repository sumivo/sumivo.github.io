Habit Goal Progress Calculator

Aiming to do a habit on 80% of days this month? See where you stand and what's still possible.

How it's calculated

Days needed = goal % × total days − days done. If you can still miss a negative number of days, the goal is out of reach, so aim for the best possible.

Worked example

InputValue
Days in the challenge30
Days so far18
Days you did it13
Goal % of days80
ResultValue

Days you can still miss1
Best possible result83.3%
