How Long Will My Savings Last? Calculator

Enter your savings, monthly withdrawal and expected return to see how long the money lasts, and the withdrawal that never runs out.

How it's calculated

Months n = −ln(1 − r × savings ÷ withdrawal) ÷ ln(1 + r).

Questions

Does this include inflation?

No. Use a return after inflation (for example 3–4%) to keep withdrawals in today's money.
